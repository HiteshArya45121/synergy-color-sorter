## How to Use
1. Extract all files maintaining the folder structure
2. Open `index.html` in a web browser
3. All pages are interlinked and fully functional
4. Customize colors by editing CSS variables in `style.css`
5. Update contact information in all HTML files
6. Replace placeholder content with actual company information

## Customization Tips
- **Colors**: Edit CSS variables at the top of `style.css`
- **Fonts**: Change Google Fonts link in HTML head
- **Images**: Replace images in `assets/images/` folder
- **Content**: Update text directly in HTML files
- **Animation Speed**: Adjust transition variables in CSS
